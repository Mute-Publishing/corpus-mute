# Changelog

## 2026-11-22

### Short links and QR codes for wiki pages and items (local)

- The UrlShortener extension only offers "Get shortened URL" in the Tools sidebar (Vector etc.) or in Minerva's mobile view,
  so with Minerva as the desktop skin there was no way to it. `config/mute-local-settings.php` now adds the same entry to
  Minerva's "..." page menu on desktop (hook `SkinTemplateNavigation::Universal`), and sets
  `$wgUrlShortenerQrCodeShortenLimit = 0` so QR codes always encode the short link.
- Verified locally in the browser on `Item:Q4`: the entry opens a popup with the short link (`/r/8`), the alternative link,
  the QR code and a working "Download QR code" (`qrcode.svg`); both links redirect (301) to the item. Other hosts
  (wikidata.org) are still refused.
- Guide updated: `docs/url-shortener.md`, section "Short links and QR codes for wiki pages and items".

## 2026-11-21

### Query UI "Short URL" fixed: own URL shortener instead of TinyURL (local + production)

- The Query UI link shortener failed with 403 for long query URLs (TinyURL behind Cloudflare). It now uses MediaWiki's
  `UrlShortener` extension (`REL1_46`, cloned into `wikibase-suite/config/extensions/`, gitignored): short links are
  `https://corpus.metamute.org/r/N`, created by `POST /w/api.php action=shortenurl` on the same origin.
- Traefik: new `shorturl-router` / `shorturl-rewrite` in `config/traefik-dynamic.yml` rewrite `/r/CODE` to
  `/wiki/Special:UrlRedirector/CODE` (Apache has no `/r/` rule). Frontend configs use `"urlShortener": "local"`; the patched
  `init.mjs`/`embedInit.mjs` add that provider (generated by the new `scripts/patch-wdqs-shortener.sh`, tested against the
  stock `wikibase/wdqs-frontend:2` files). The TinyURL `/shorten` proxy was removed from `wdqs-frontend-entrypoint.sh`.
- `urlshortcodes` is excluded from `sync-db.sh` / `sync-env.ps1`. `server-branding.sh` now installs the extension and
  runs `update.php --quick`.
- **Deployed to production** (backup first: `/var/backups/mute-wikibase/20261121-160550`; replaced config files in
  `/opt/mute-wikibase/config/bak-20261121-160539`). Verified on https://corpus.metamute.org/: a 2,085-character query URL
  shortens to `/r/3`, redirects (301) back to the query, unknown codes give 404, and the UI button shows the short link.
  `/r/3` is a test link (padded dummy query).
- New documentation for other Wikibase operators: [`docs/url-shortener.md`](docs/url-shortener.md).

## 2026-11-19

### Production taken offline (security incident, precaution)

- Following a security incident with no known harmful effects so far, `corpus.metamute.org` (`178.105.222.174`) was
  taken offline as a precaution.
- All 9 containers of the `mute-wikibase-prod` compose project were stopped (traefik, wikibase, wikibase-jobrunner,
  mysql, elasticsearch, wdqs, wdqs-updater, wdqs-frontend, quickstatements). Ports 80/443 have no listeners.
- The host `nginx` service was stopped and disabled (it was already inactive; no nginx container exists).
- No data, volumes, backups or config were deleted, so they are available for forensics and recovery.
- Containers use `restart: unless-stopped`, so they will not come back on reboot after a manual stop.
- The service stays offline until the incident is resolved. To restore it, follow
  "Taking production offline and restarting it" in `wikibase-deploy/README.md`.
